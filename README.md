## 🚀 Tech Stack
- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [TailwindCSS v4](https://tailwindcss.com/) with custom SpaceX-inspired futuristic pitch-dark design system
- **Icons**: [Lucide React](https://lucide.dev/)
- **Interactive Effects**: Canvas Confetti, Intersection Observer Scroll Reveal, Glassmorphism Telemetry Cards

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```
Open `http://localhost:3001` to preview.

### 3. Build for Production
```bash
npm run build
```
Generates production-optimized bundle in `dist/`.
